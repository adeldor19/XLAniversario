# XL Aniversario · VR Wagon

Prototipo independiente para probar un recorrido VR tipo vagón.

El espectador permanece estable en VR mientras el entorno se desplaza. Incluye WebXR, dos mandos, cámara estable, tres estaciones, aceleración, frenado, paradas automáticas e interacción básica con el gatillo.

Está preparado para GitHub Pages. La siguiente fase será adaptar el recorrido a la estética y elementos definitivos del proyecto.
